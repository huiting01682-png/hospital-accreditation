# 醫院評鑑條文對照表（區域醫院）

追蹤醫院評鑑各條文的負責單位、佐證資料、自評等級、進度、預計完成日與委員建議事項。

## 檔案

| 路徑 | 說明 |
|---|---|
| `data/standards.csv` | 評鑑條文（篇、章、條號、條文名稱、條文類別、評量項目），由醫策會條文檔轉入 |
| `data/units.csv` | 負責單位清單，作為下拉選單來源 |
| `tools/build_xlsx.py` | 產生 Excel 對照表 |
| `output/accreditation_checklist.xlsx` | 產出的 Excel：條文總表、單位清單、進度統計 |

## 產生 Excel

```
python3 tools/build_xlsx.py
```

## 欄位

- 條文欄位：篇、章、條號、條文名稱、條文類別、評量項目
- 追蹤欄位：負責單位、聯絡人、佐證資料、自評等級、進度、預計完成日、委員建議事項、待改善事項、更新日期

進度統計頁依單位彙整各進度條數、完成率、待改善條數與期程差異（預計完成日已過、尚未完成）。
